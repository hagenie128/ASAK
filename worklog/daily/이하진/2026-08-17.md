### 결제수단 필드 직렬화 이슈 확인 — `issue`

- **작업 목적:** 나연님이 API-014 결제수단 API 작업 중 필드값이 `undefined`로 내려오는 오류를 확인한다.
- **직접 확인:** 근본 원인은 Java `boolean isEnabled`를 Lombok+Jackson+MyBatis가 `enabled`로 직렬화하는 규칙 때문이었다. DB 컬럼 자체는 `active`로 정상이었고, SQL 별칭 `active AS isEnabled`를 거치며 DTO `boolean isEnabled` → JSON `enabled`로 바뀌어 프론트가 `method.isEnabled`로 접근하면 값이 없었다. **DB 변경이나 사람의 실수가 아닌 Lombok boolean 네이밍 규칙 문제.** 이후 8/18 원인 분석 문서로 정리하고 `active`로 통일하여 해결.
