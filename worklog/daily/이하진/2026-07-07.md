## 오늘 작업

### Notion 팀 가이드·학습 리소스 구조화 — `docs` / `knowledge-sharing`

- **작업 목적:** 개인이 알아낸 내용을 대화에서 소모하지 않고, 팀원이 재사용할 수 있는 Notion 하위 페이지와 Markdown 문서로 남긴다.
- **직접 구현:** Markdown 문서를 Notion 페이지로 올리고 단계별 추천·사용 목적을 포함한 가이드 구조를 사용했다. 코드 학습 자료는 알고리즘 → 문법 → 실제 프로젝트 코드 → 품질/설계 → 디버깅 → SQL 순으로 묶었다.
- **AI 도움:** AI가 설명한 내용을 그대로 보관하지 않고, 프로젝트 코드와 연결된 예시·검증 순서를 요구해 팀용 문서로 재가공했다.
- **이슈:** 개인 질문·디버깅 내용이 대화에서 소모되고 팀에 남지 않음 → Notion/Markdown 기반 학습 자산으로 전환.
- **검증:** 문서 구조·가이드 설계 작업이며, 팀원의 실제 사용 여부는 이 기록만으로 확인되지 않는다.
- **포트폴리오 요약:** 프로젝트 중 얻은 지식을 팀 재사용 가능한 학습 자산으로 구조화했다.
