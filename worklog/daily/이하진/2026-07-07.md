## 오늘 작업

### 개인 질문을 팀 학습 자산으로 전환 — `docs` / `knowledge-sharing`

- **작업 목적:** 대화에서만 소모되는 설정·디버깅·학습 내용을 팀원이 다시 사용할 수 있는 Notion 하위 페이지와 Markdown 문서로 남긴다.
- **직접 판단:** 학습 자료를 단순 문법 목록으로 두지 않고, 알고리즘 → 문법 → 프로젝트 코드 → 품질/설계 → 디버깅 → SQL 순으로 실제 프로젝트 문제와 연결했다.
- **문서 운영:** Markdown 원문, Notion 안내 페이지, 단계별 추천 이유를 분리해 정보가 늘어도 찾을 수 있는 구조를 만들었다.
- **협업 의미:** 개인이 알아낸 해결 방법을 다음 사람이 처음부터 다시 찾지 않아도 되도록, 작업 기록과 학습 자료를 연결했다.

## AI 활용 메모

- AI 설명을 그대로 저장하지 않고, ASAK 코드와 연결된 예시·확인 순서·재현 조건이 있는지 검토해 팀용 문서로 재가공했다.
- AI가 만든 광범위한 학습 목록은 현재 스프린트에서 필요한 순서로 좁혔다.
