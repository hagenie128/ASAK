# 2026-07-06 키오스크 아이콘 프롬프트·Figma 자산 기준

> 일일: [2026-07-06](../../daily/이하진/2026-07-06.md)

## 1. 기본 정보

- 작업 날짜: 2026-07-06
- 담당자: 이하진
- 저장소: ASAK-Kiosk (Figma 자산)
- 브랜치/커밋: 근거 없음 — 대화 기반 판단 기록
- 작업 유형: `design-system` / `ai`

## 2. 작업 목적

- AI 생성 이미지를 임의의 장식물이 아니라, 실제 키오스크 UI에서 재사용할 수 있는 일관된 자산으로 만든다.

## 3. 직접 구현 영역

- 아이콘 기준을 **투명 PNG, 배경 없음, 단조롭고 명확한 형태**로 잡고, 텍스트·숫자·로고·불필요한 그림자 등 금지 조건을 명시했다.
- 컬러 팔레트, Figma 컴포넌트 기준, 화면 매핑, 후처리 체크리스트까지 프롬프트 구조에 포함했다.

## 4. 구현 로직 / 적용한 방식

- 1차 이미지 프롬프트를 그대로 사용하지 않고, 시각 묘사 → 금지 요소 → 컬러 팔레트 → Figma 컴포넌트 기준 → 화면 매핑 → 후처리 체크리스트 순으로 다시 구조화했다.

## 5. AI 도움 영역

- 사용한 AI 도구: 이미지 생성 AI (도구명 불명 — 대화 기반 기록)
- 요청 내용: 키오스크 아이콘 세트 생성
- 도움 준 내용: 1차 아이콘 이미지 초안
- 그대로 사용한 부분: 없음 — 1차 결과를 그대로 채택하지 않음
- 수정해서 사용한 부분: 프롬프트 자체를 시각 묘사·금지 요소·컬러 팔레트·컴포넌트 매핑·후처리 체크리스트로 재구조화

## 8. 이번 작업에서 배운 점

- 생성형 AI 산출물도 "마음에 들면 사용"이 아니라 디자인 시스템·컴포넌트·화면 역할과 맞는지 검증하는 방식으로 관리해야 한다.

## 10. 검증 내용

- 이 항목은 프롬프트·기준 설계 기록이며, 실제 생성된 아이콘이 Figma 컴포넌트에 반영·검증된 근거는 이 기록만으로는 확인되지 않는다.

## 11. 포트폴리오용 요약

AI 생성 아이콘을 장식이 아닌 구현 자산으로 다루기 위해 투명 배경·형태·금지 요소·컬러·컴포넌트 매핑 기준을 프롬프트 단계부터 설계했다.
