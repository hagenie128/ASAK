## 2. 작업 목적

- 로컬 Vite(5173)에서 `/api` 요청을 `http://localhost:8080`으로 넘겨 개발 연동을 단순화한다.

## 3. 직접 구현 영역

- `vite.config.js` `server.proxy["/api"]` → `target: http://localhost:8080`, `changeOrigin: true`

## 4. 구현 로직 / 적용한 방식

- 프론트는 상대 경로 `/api/...`를 쓰고, 개발 서버가 백엔드로 프록시.
- 프로덕션 빌드 배포 경로와는 별개.

## 5. AI 도움 영역

## 6. 발생 이슈
