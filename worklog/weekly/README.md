# 주간 rollup (weekly)

> Status: **CURRENT**
> 공식 회의록이 아닙니다. 회의록 정본은 [`../../docs/operations/meeting-minutes/`](../../docs/operations/meeting-minutes/README.md)입니다.

매주 금요일 또는 스프린트 종료 시 주간 요약을 작성합니다.

## 파일명

`YYYY-Www.md` (ISO 주차, 예: `2026-W32.md`)

## 포함 항목

- 이번 주 완료 / 진행 / 다음 주 계획
- 팀 블로커·리스크
- **daily 링크 모음** — 해당 ISO 주차에 존재하는 `daily/{이름|/_team}/*.md` 전부 (담당자별)
- `entries/{이름}/` 링크 (있을 때)
- **관련 문서** — 주차 회의록·wiki·ai-reports·study
- 포트폴리오용 한 줄 요약
