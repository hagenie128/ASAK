# 프로젝트 완료 체크리스트 문서화 (2026-09-01)

## 대상

- 새 문서: `docs/wiki/project-completion-checklist-2026-09-01.md`
- 기준: `docs/wiki/wbs.md`, `docs/wiki/qa-test-cases.md`, 릴리스/데모 운영 문서

## 반영 원칙

- WBS의 미완료 항목을 번호 순서대로 유지했다.
- 이미 `DONE`인 항목은 반복 구현 대상으로 넣지 않았다.
- 실제 관리자·백엔드 QA 근거와 고객(Kiosk)/실PG 미검증 범위를 분리했다.
- 코드·DB·원격 Git은 변경하지 않았다.

## 남은 결정

- 실제 PG 환불을 MVP 완료 조건에 넣을지 팀이 확정해야 한다.
- RTOS는 콘솔 시연을 MVP 종료 조건으로 둘지, 발표 범위에서 제외할지 확정해야 한다.
- WBS의 모든 항목을 완료할지, 범위 조정 항목을 공식 제외 처리할지 팀이 결정해야 한다.
