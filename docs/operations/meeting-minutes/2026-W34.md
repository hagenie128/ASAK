### 검토했으나 채택하지 않은 안

- `isEnabled` 유지 + 프론트에서 `enabled`로 접근 — Lombok 규칙에 프론트를 맞추면 혼란 가중 → **`active` 통일로 결정**
- 깨진 옵션 4개 DB 물리 삭제 — 과거 주문 이력 영향 → **active=0 숨김 처리로 결정**

## ⚠️ 확인 필요 사항

1. PPT 초안(`docs/00-presentation`)은 RTOS를 **금지 키워드**로 적어 두었다. 선생님 8/18 지시(RTOS 연동)와 충돌한다. 발표에 넣을지, 구현만 하고 슬라이드에서는 빼는지는 **결정 필요**.
2. `API-019` `/api/orders/{orderId}/receipt-print`는 명세에만 있고 **Week 5 MVP 제외**로 적혀 있다. 8/21 최소 범위로 살릴지 **결정 필요**.
3. QR/멤버십 스캔(`RTOS-DEVICE-004~006`, `API-020`)은 기존 EXCLUDED 유지.
4. `UserMenuMapper`·`UserOrderMapper`가 `opi.active`를 필터링하지 않아, DB에 `active=0`을 넣어도 **화면·주문에 반영 안 됨**. 코드 수정·회귀 확인 후 처리 필요.
5. `.env` 값(DB URL·Cloudinary API Secret)이 카톡으로 공유됨 — **프로젝트 종료 후 키 로테이션 필요**.
6. 매출 API(`AdminSalesController`)는 DB 뷰 존재 전제 — **런타임 E2E 미실행**.
