## 1. 그리드 — 정사각 6모듈

Abstract Squares의 `1.88 in` 정사각형을 그리드 단위로 승격한다.

```
캔버스      13.333 × 7.5 in
좌우 여백    0.48 in
콘텐츠 폭    12.373 in
모듈 M      1.88 in (정사각)
gutter g    0.22 in
칼럼        6  →  6 × 1.88 + 5 × 0.22 = 12.373  ✅ 정확히 맞음
```

### 가로 스팬

| 스팬 | 폭 | 용도 |
|---|---:|---|
| 1col | 1.88 | 아이콘 블록, 스텝 |
| 2col | 3.98 | 좌측 설명 열 |
| 3col | 6.08 | 2분할 |
| 4col | 8.18 | 화면 캡처 열 |
| 5col | 10.28 | 와이드 표 |
| 6col | 12.373 | 풀 폭 |

### 세로 영역

| 영역 | y | 높이 |
|---|---:|---:|
| 헤더 (제목 + 룰) | 0.36 | 0.93 |
| 콘텐츠 | 1.60 | 5.30 |
| 푸터 | 6.95 | 0.30 |

세로 모듈: `1.66 + 0.22 gutter` → 3행 = `1.66×3 + 0.22×2 = 5.42` ≈ 콘텐츠 높이

### 예외

- **T08 ERD**: 좌우 여백 `0.30`, 콘텐츠 폭 `12.733` (도식 우선)
- **T03 개요 5카드**: 5트랙 예외 (폭 `2.315`, gutter `0.24`). 이 슬라이드에만 허용.

> 모든 요소의 x 시작은 `0.48` 또는 칼럼 경계(`0.48 + n × 2.10`)에 스냅한다.

## 3. 타이포그래피

### 3.1 폰트 — Pretendard 단일 시스템

설치 완료 (SIL OFL, 임베딩 허용). 등록된 패밀리:

```
Pretendard            (Regular 400 / Bold 700)
Pretendard Light      Pretendard Medium
Pretendard SemiBold   Pretendard ExtraBold   Pretendard Black
```

**PowerPoint 지정 규칙 (중요)**

- Pretendard의 중간 웨이트는 **별도 패밀리명**으로 등록된다.
  SemiBold를 쓰려면 폰트명을 `Pretendard SemiBold`로 지정하고 **굵게(B) 버튼은 끈다.**
  `Pretendard` + B = Bold(700). 두 방식을 섞지 않는다.
- 한글·영문·숫자 모두 Pretendard로 통일. 라틴 대체 폰트 지정 금지.
- **저장 시 `파일 → 옵션 → 저장 → 파일에 글꼴 포함 → 사용 중인 문자만` 반드시 체크.**

**함께 설치한 대안 폰트 (이번 덱에서는 미사용)**

| 폰트 | 상태 | 판단 |
|---|---|---|
| Paperlogy (9웨이트) | 설치됨 | 자간이 넓고 획이 균일해 **표지 대제목**에는 어울리나, 본문에서 같은 폭에 들어가는 글자 수가 줄어 정보량 많은 결과보고서에 불리. 라이선스 원문이 패키지에 없어 임베딩 가부 미확인 → **보류** |
| SUIT Variable | 설치됨 (OFL) | Pretendard와 인상이 거의 겹침. 병용 이득 없음 → **미사용** |

> 표지만 Paperlogy ExtraBold로 바꾸고 싶다면 배포처(freesentation.blog)에서 임베딩 허용을 먼저 확인한다.

### 3.3 문장 규칙

- 카드 본문 최대 3줄, 슬라이드당 완결 문장 6개 이하
- 줄바꿈은 의미 단위 수동 분리 (초안 md의 `text` 블록 줄바꿈 그대로)
- 마침표는 서술문에만. 표 셀·라벨·칩에는 쓰지 않는다
- 자간 0, 장평 100% 고정 (Pretendard 기본값이 이미 조밀하다)

## 4. 사각 모티프 규칙

이 덱의 유일한 장식 언어다. 원 · 삼각형 · 물결 · 그라데이션은 쓰지 않는다.

| 형태 | 규격 | 색 | 사용처 |
|---|---|---|---|
| `square/module` | 1.88 × 1.88 | 4개 중 1개만 `#B5E30F`, 나머지 `#FFFFFF` + 1pt `#E5E7EB` | 개요·구조 슬라이드 강조 |
| `square/index` | 0.14 × 0.14 × 5칸, gap 0.03 | 현재 섹션 `#B5E30F`, 나머지 `#E5E7EB` | 모든 본문 슬라이드 우상단 |
| `square/dot` | 0.10 × 0.10 | `#B5E30F` | 푸터 좌측, 리스트 불릿 |
| `rule/accent` | 1.60 × 0.05 | `#B5E30F` | 제목 아래 |
| `bar/vertical` | 0.11 × 1.58 | `#B5E30F` α 100 / 60 / 30 | 표지·마무리만 |
| `bracket` | 5.44 × 1.58, 선 1.25pt | `#FFFFFF` α 70 | 표지 제목 상하 |

**규칙**

- 모서리는 전부 **직각(radius 0)**. 유일한 예외는 화면 캡처 프레임(radius 0.06).
- 세로바는 3~4개, 서로 다른 투명도, 불균등 간격(1.00 / 0.60 / 0.30 비율).
- 본문 슬라이드에는 `square/index` · `rule/accent` · `square/dot` 외 장식을 넣지 않는다.
- 모티프와 텍스트 최소 이격 0.30 in.

### pptxgenjs 함정 (실제로 겪은 것)

- **음수 폭/높이 도형이 파일을 깨뜨린다.** `addShape(line, { w: -0.23 })` → 검증기는 통과하지만 **PowerPoint가 파일을 열지 못한다.** 좌향 선은 시작점을 왼쪽으로 옮기고 양수 폭을 쓴다.
- `pres.layout`은 슬라이드 추가 **전에** 설정. 기본값은 10 × 5.625in이라 좌표가 캔버스 밖으로 나간다.
- 색상 hex에 `#`이나 알파 8자리를 쓰면 파일이 깨진다. 투명도는 `transparency: 0-100`.
- 텍스트 상자 기본 안쪽 여백이 있으므로 도형과 정렬하려면 `margin: 0`.
- `validate.py`는 시스템 기본 인코딩으로 파일을 열기 때문에 한국어 Windows에서는 `PYTHONUTF8=1`이 필요하다.
