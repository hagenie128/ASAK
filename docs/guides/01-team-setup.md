# 팀 설정 가이드

> Status: **REFERENCE**

설치와 실행 절차는 [ASAK 시작 안내](../operations/setup/getting-started.md)를 정본으로 사용합니다.

## 팀 공통 규칙

1. `ASAK`, `ASAK-Kiosk`, `ASAK-Admin`, `ASAK-back`은 독립 저장소로 관리합니다.
2. 작업 전에 담당 저장소에서 `git status`와 현재 브랜치를 확인합니다.
3. WBS·Issue·작업 범위를 확인한 뒤 기능 브랜치를 만듭니다.
4. 화면만 보지 말고 API·DB 결과까지 검증합니다.
5. 완료 근거는 커밋, 테스트 결과, 워크로그에 남깁니다.
