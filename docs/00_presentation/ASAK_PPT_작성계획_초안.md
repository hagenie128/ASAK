## 0. 덱의 한 줄 메시지

> **ASAK(A Salad A Kiosk)** — 옵션이 많은 샐러드 주문을
> **실수 없이** 끝내는 키오스크와, 그 주문을 받는 관리자 화면.

### 청중이 기억할 3가지

1. **왜 샐러드인가** — 메뉴+옵션+제외+수량이 겹치는 고복잡도 주문
2. **무엇을 만들었는가** — Kiosk ↔ API ↔ Admin 으로 연결되는 주문 루프
3. **어떻게 검증하는가** — 화면만 아니라 옵션 정책·금액·상태를 서버에서 다시 확인

### 발표 톤 (2026 트렌드 × ASAK)

| 트렌드 (시장)                   | ASAK가 실제로 말하는 방식                                     |
| ------------------------------- | ------------------------------------------------------------- |
| 셀프오더 확산 · 커스터마이징 UX | “추천 AI”가 아니라 **옵션 정책·제외·품절을 흐름에 넣는 UX**   |
| 실시간 재고·메뉴 동기화         | **품절·수량 제한이 목록·상세·검증에 반영**되는 구조           |
| 키오스크 ↔ 주방/운영 연동       | **Live 주문·상태**로 고객 주문을 운영 화면까지 이어줌         |
| 속도보다 정확도                 | Product Bible UX: **빠르게 누르기보다 실수 없이 끝내기**      |
| 계약 기반 풀스택                | Product Bible · Screen Bible · API 명세 · ERD로 **문서→코드** |

**넣지 않는 트렌드 키워드:** AI 추천, Face Pay, 서빙 로봇, 음성 주문, 매출 n% 증가 — 미구현·미검증.

## 3. 슬라이드별 스토리보드

각 슬라이드 형식:

- **화면 헤드라인** — 슬라이드에 찍히는 큰 문장
- **카피** — 카드/표에 넣을 짧은 문구
- **비주얼** — 템플릿·캡처 힌트
- **발표 노트** — 말할 내용 (화면에 안 씀)
- **금지** — 과장·미구현 표현

### 12쪽 — 핵심 기능 · 메뉴 목록 · T10-K

**화면 헤드라인:** `메뉴 목록 및 카테고리 선택`

**본문**

```text
카테고리별 메뉴를 조회하고
이름 · 가격 · 이미지 · 품절을 한눈에 확인합니다.
원하는 메뉴를 선택해 상세로 이동합니다.
```

**포인트 바:** `품절 메뉴는 선택 전에 막는다 — 주문 실패를 앞당기지 않는다.`
**캡처:** 실제 Kiosk 메뉴 목록 (9:16)
**발표 노트:** “목록은 시작점입니다. 여기서 이미 품절을 보여 잘못된 상세 진입을 줄입니다.”

---

### 13쪽 — 핵심 기능 · 메뉴 상세·옵션 · T10-K ★핵심 장

**화면 헤드라인:** `메뉴 상세 및 옵션 선택`

**본문**

```text
필수 · 선택 옵션을 정책(min/max)에 맞게 고릅니다.
제외 가능한 재료만 빼고, 수량을 조정합니다.
가격 변화는 선택과 함께 확인합니다.
```

**포인트 바:** `화면 규칙 = 서버 재검증. 옵션·품절·수량을 주문 전에 다시 본다.`
**발표 노트:**
“ASAK의 차별점은 이 화면입니다. 트렌드로 말하면 ‘커스터마이징 UX’이고, 저희 말로 하면 **실수 없이 조합을 완성하는 화면**입니다. 필수/선택, 추가/제외를 섞지 않고 보여 줍니다.”

### 14쪽 — 핵심 기능 · 장바구니·결제 · T10-K

**화면 헤드라인:** `장바구니 및 결제 이동`

**본문 (시연 범위에 따라 분기)**

```text
[공통]
선택한 메뉴 · 옵션 · 제외 · 수량 · 금액을 확인합니다.

[A. 결제 API 시연 가능]
결제 수단 선택 후 승인 결과와 주문번호를 확인합니다.

[B. 결제 연동 전 — 기본 권장]
주문 내용을 검토한 뒤 결제 화면으로 이동합니다.
```

**팀 확정:** A / B 중 하나만 PPT·시연에 사용. 섞지 말 것.
**발표 노트:** “장바구니는 ‘마지막 검산’ 화면입니다. 실패해도 선택을 잃지 않는 것이 UX 원칙입니다.”

### 15쪽 — 핵심 기능 · 관리자 주문 관리 · T10-A

**화면 헤드라인:** `관리자 주문 관리`

**본문**

```text
Live 보드와 주문 목록에서
번호 · 메뉴 · 상태를 확인합니다.
상세에서 옵션 · 제외 재료까지 봅니다.
```

**포인트 바:** `고객 주문 → 운영 화면. 키오스크는 주문의 시작, Admin은 처리의 시작.`
**발표 노트:** “셀프오더 트렌드의 다른 축은 운영 연동입니다. 주문이 키오스크에서 끝나면 안 되고, 매장 화면까지 와야 합니다.”
