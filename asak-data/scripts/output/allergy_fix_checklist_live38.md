# 알레르기 수정 체크리스트 (공식표 정본)

- 정본: `allergy_260715.csv` (적용범위=SALADY 우선)
- 대상: 라이브 DB 메뉴 불일치 **36건**
- 원칙: 메뉴 알레르기 테이블을 만들지 않고, `ing_allergen`(필요 시 `menu_ing`)를 공식표에 맞춤

## 작업 요령

1. **missing_vs_csv**: 공식표에 있는데 화면 합산에 없음 → 해당 알레르기를 가진 재료에 `ing_allergen` 추가 (고신뢰 후보 우선)
2. **extra_vs_csv**: 합산에만 있음 → 그 알레르기를 넣는 재료의 `ing_allergen` 제거 검토, 또는 기본 재료에서 제외 검토 (다른 메뉴 영향 주의)
3. 같은 `ing_id`를 여러 메뉴가 쓰므로, 재료 수정 전 **다른 메뉴 영향**을 확인
